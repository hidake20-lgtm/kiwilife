# 墨斬 Sumi-Giri

水墨風 3D 單人動作冒險（Three.js，單一 HTML 檔）。獨行武士一路斬鬼，最後討伐大魔王「百目鬼王」。

## 流程
序·山門 → 斷魂崖（餓鬼）→ 浮石小徑 → 腐骨林（屍蜈、百眼肉瘤）→ 祠 → 百眼窟（中頭目「肉山·縫屍巨漢」）→ 骷髏鳥居長橋 → 墨淵（百目鬼王，兩階段）

## 操作
| | 鍵盤/滑鼠 | 手把 |
|---|---|---|
| 移動 / 視角 | WASD / ←→ 或滑鼠（點畫面鎖定） | 左 / 右搖桿 |
| 斬擊（三段連斬，空中為下劈） | J / 左鍵 | X |
| 居合（長按蓄力、放開突進） | K / 右鍵 | Y |
| 翻滾閃避（無敵，貼身閃過觸發「見切」慢動作） | L / Shift | B |
| 跳（可二段跳） | Space | A |
| 飲藥 / 奧義「墨月斬」/ 鎖定 | R / Q / Tab | LB / RT / RB |

手機：左半邊拖曳移動、右半邊滑動轉視角，右下有斬、居、閃、跳、藥、奧、鎖按鈕。

祠前休息會補滿體力與藥葫並設為重生點；擊破削韌（「破綻」）可讓敵人硬直。
