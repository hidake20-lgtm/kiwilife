# 墨峰 Ink Peaks

四人水墨風 3D 動作遊戲（Three.js，單一 HTML 檔，無需建置）。

## 遊玩
直接用瀏覽器開 `index.html`（需要網路載入 Three.js 與字型），或放到 GitHub Pages。

- **奪燈（競技）**：群峰上搶靈燈，衝斬打散對手的燈；被打越多次飛越遠，擊落雲海得分。兩分鐘結算，最後 20 秒金燈加倍。
- **守燈（合作）**：守護古燈撐過五波墨魅（墨影、墨傀、最終 Boss 墨蛟）。隊友倒下時靠近即可扶起。

## 操作（最多 4 人，空位由電腦補上）
| 輸入 | 移動 | 跳（空中可二段翻身跳） | 衝斬 |
|---|---|---|---|
| 鍵盤 A | WASD | Space / C | F / V |
| 鍵盤 B | 方向鍵 | . / K | / / L |
| 手把 | 左搖桿 | A | X / B / RB |
| 觸控 | 左半邊拖曳 | 跳 | 斬 |

Esc / Start 暫停，M 靜音。手把在選單按 A 自動加入空位。

## 技術
全部美術與音效皆為程式生成：水墨岩石三面投影貼圖、卡通著色、深度描邊後製（墨線 + 宣紙紋 + 暗角）、Karplus-Strong 撥弦音效。
